# 🎓 JUIT Guide

### Your AI-powered campus companion for Jaypee University of Information Technology

**JUIT Guide** is a student-focused web application designed to make campus life easier for new and existing students at **Jaypee University of Information Technology (JUIT), Waknaghat, Solan**.

From finding a classroom or faculty cabin to understanding Moodle, Campus Lynx, campus facilities, and university services, JUIT Guide brings essential campus information together in one place.

> 🚀 **Built for Hack Days Solan**

---

## 📌 Problem Statement

For new students, navigating a university campus can be confusing.

Students often need to search through different sources or ask seniors for basic information such as:

* Where is a particular classroom?
* Where is a faculty cabin?
* Who should I contact for a specific issue?
* How do I use Moodle?
* Where is the library or cafeteria?
* Where can I find laundry facilities?
* How do I navigate different areas of the campus?
* Which university office handles a particular request?

JUIT Guide aims to reduce this confusion by providing a **single digital campus companion**.

---

## 💡 Our Solution

JUIT Guide combines:

**Campus Information + Navigation + AI Assistance**

into one easy-to-use platform.

The application provides students with structured campus information while **JUIT Buddy**, the integrated AI assistant, helps users find information and understand university-related processes through natural-language interaction.

# ⚙️ Installation & Setup

To run the project locally:

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/JUIT-Guide.git
```

### 2. Enter the project directory

```bash
cd JUIT-Guide
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create the required environment configuration file and add your Firebase / Gemini configuration.

**Do not upload your API keys to GitHub.**

### 5. Start the development server

```bash
npm run dev
```

The application should then be available through the local development URL provided by the framework.
